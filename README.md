# 42K ペース配分ラボ

フルマラソンのペース配分を変えたときに、糖の残量・脚の疲労・失速地点・ゴールタイムがどう変わるかを試せるシミュレーターです。HTMLファイル1枚で動き、ビルドは不要です。

## 使い方

`index.html` をブラウザで開くか、GitHub Pages で公開します。

入力項目は次のとおりです。

- **ランナー**：閾値ペース、体重、糖の貯蔵量
- **レース条件**：目標タイム、補給量（g/時）、気温
- **回復**：一時的な疲労の回復の速さ（半減期）、回復に回れる強度の上限、筋損傷の回復率
- **配分**：前後半差、最初の10kmの突っ込み

## モデルの概要

42.195kmを100m刻みで計算します。

- **エネルギー消費**：1kmあたり「体重 × 1.0 kcal」。疲労と暑さで少し増えます。
- **糖の割合**：強度 `I = 速度 ÷ 閾値速度` に対して `0.25 + 0.75 × ((I−0.5)/0.5)^4`。強度に対して下に凸の関数です。補給は時間あたりで糖に加算します。
- **筋損傷**：`I` が0.72を超えた分の4乗で蓄積します。通常は回復しない設定です。
- **一時的な疲労**：強度が上限を超えるとたまり、下回ると指数関数的に回復します（W′バランスモデルと同じ考え方）。
- **実際の速度**：「計画の速度」と「閾値速度 × (1−筋損傷) × (1−一時的な疲労) × 糖係数」の小さい方。糖係数は残量12%以下で下がり始め、0%で0.68になります。

係数は一般的な生理学の傾向に合わせた仮の値です。数値そのものより、配分による差の向きと大きさを見るためのモデルです。
